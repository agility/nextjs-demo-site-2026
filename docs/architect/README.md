# Demo Site: Architecture Overview

> **Website**: https://demo.agilitycms.com/

This guide provides instance-specific architectural information for the Demo Site. For generic Agility CMS architecture concepts, see the [official Agility CMS Training Guide](https://agilitycms.com/docs/training-guide).

## Demo Site Architecture

The Demo Site is a comprehensive Next.js application showcasing modern headless CMS patterns, AI-powered search, internationalization, and advanced caching.

### Technology Stack

- **Framework**: Next.js 16.3.5 with App Router
- **React**: 19.3.0
- **TypeScript**: Full type safety
- **Styling**: Tailwind CSS v4
- **CMS**: Agility CMS (@agility/nextjs 16.0.8)
- **Animations**: Motion (Framer Motion alternative)
- **AI**: Azure OpenAI + Algolia integration
- **Analytics**: PostHog integration
